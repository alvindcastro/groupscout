# Workflow Sources

This folder separates workflow JSON sources into two explicit buckets:

- [codebase/](./codebase/)  
  Last committed repo versions of the MVP workflow JSON files.

- [deployed-live/](./deployed-live/)  
  Working exports pulled from the live n8n deployment and used as the current deployed source of truth.

## Current Convention

- `docs/mvps/mvp-a/n8n_workflow.json`
- `docs/mvps/mvp-b/n8n_workflow.json`
- `docs/mvps/mvp-c/n8n_workflow.json`

These top-level workflow files currently match the `deployed-live/` copies.
