# LUX MVP UI/UX Pack

This folder is a no-code planning pack for a unified LUX operator product built around the three existing MVPs.

Files:
- `LUX_MVP_UI_UX_SPEC.md` - shared product shell, module behavior, status model, and MVP scope
- `LUX_MVP_SCREEN_BLUEPRINTS.md` - low-fidelity screen definitions and ASCII wireframes
- `LUX_MVP_PROMPT_PACK.md` - detailed reusable prompts for future UX/spec/design/planning sessions

Working assumptions:
- One product shell should unify the MVPs
- Each MVP still needs a distinct review surface
- Slack, Airtable, Buffer, and JobTread remain integrations, not the primary UI
- No production code is included in this pack
